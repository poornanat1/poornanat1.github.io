Monochrome editorial design informed by the portfolio index in the supplied Cosmos reference. An academic personal website: clear identity, concise context, inspectable work, and readable experience.

Palette

Paper / #FFFFFF
Ink / #171717
Muted / #656565
Rule / #D5D5D5
Surface / #F5F5F5

The portrait is grayscale; project screenshots retain their original colors as evidence of the products. Interface colors remain neutral. Selection and expanded project headers invert to white on black.

Typography

Helvetica Neue, Helvetica, Arial, sans-serif. Display: 48–76px, regular, tight tracking. Section labels: 16px. Project titles: 15–16px. Descriptions: 13–14px with 1.75 line height. Monospace labels and metadata: 9–11px. Font files are not requested from external services.

Use literal section names and descriptive copy. Reserve large type for the person’s name. No promotional slogans.

Grid & spacing

1080px content width with fluid margins. Section grid: 175px label rail and flexible content column with a 25px inset and vertical rule. Below 700px the rail becomes a simple section heading. Shared spacing: 4, 8, 12, 16, 24, 32, 48px.

Rules organize information. Avoid shadows, decorative shapes, rounded cards, pills and ornamental badges.

Information retrieval

A concise account of the problem, contribution and evidence. Use native details and summary for keyboard-operable expansion. The plus becomes a minus; the selected row inverts.

Motion

One 500ms entrance for the introduction, moving only 5px. Expanded details fade in over 280ms with 3px movement. Hover transitions use 180ms. No continuous animation, scroll-gated content or image zoom. Reduced-motion preferences disable all transitions, animation and smooth scrolling.

Interaction & accessibility

Links remain underlined in body content. Focus uses a 2px black outline with 5px offset. Native disclosures expose expanded state. The page includes a skip link, heading hierarchy, descriptive alt text, responsive layouts and meaningful text without animation.

This reference documents intended patterns; it is not an accessibility certification. Test keyboard, screen readers, text zoom and contrast before publication.
